Duo NELBO bits/atom is a stochastic conditional-canvas variational bound. It is not autoregressive BPB and is never placed on the same numeric axis as nanoGPT’s challenge BPB. Across families, GSM task accuracy and the frozen external scorer are the generation-quality comparisons.

Exactly how GSM8K evaluation ran

  1. Each held-out GSM8K question was rendered with five worked training exemplars using the harness format. Seeds 0, 1, and 2 select matched exemplar rows for both models; every seed covers all 1,319 test questions.
  2. The prompt is clean and is never noised. Byte-Duo encodes the literal UTF-8 prompt as fixed conditioning. Only a new 512-atom continuation canvas is initialized from the diffusion prior and iteratively denoised.
  3. The reported main decode uses 48 categorical reverse transitions, a 512-byte/atom semantic cap, batched generation at 32 requests, atomic EOT, strict UTF-8 validation, and the same textual stop strings as nanoGPT. Stop delimiters are removed before task scoring.
  4. nanoGPT uses greedy cached autoregressive decoding with the same prompt, exemplars, response byte cap, stop rules, and held-out rows. Its natural unit is a GPT-2 token; Byte-Duo’s is an atomic byte/control.
  5. The external sample BPB is P(response) under one separately trained frozen causal byte model. It measures fluency of generated samples, not likelihood under either generator. Inputs are stop-trimmed identically and the full 3×1,319 cohort is authenticated.
